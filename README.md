# Get a Nob

A tiny, judgmental doorman for your face.

Connect X. Nob draws a profile picture of you as himself, using Grok Imagine. Then you take it to Twitter.

## The door

1. **Connect to Twitter**
2. **Generate**
3. **Change to your Twitter PFP** or **Share**

Nob cannot stamp your X profile for you. X does not hand that key to a doorman. The file is saved to your machine and X settings opens so you can pick it.

## Stack

TanStack Start, Better Auth (X via the Grok broker), Grok Imagine (`grok-imagine-image-2.0`), Postgres.
